# Football Analysis Desktop App

A desktop application for analyzing international football data using interactive visualizations and statistical insights.

The application allows users to explore football datasets, visualize trends, and perform basic data analysis through a graphical interface.

## Features
- Load and analyze football-related datasets
- Visualize statistics using charts and graphs
- Store and retrieve data using MongoDB
- Desktop GUI built with PyQt
- Data processing with pandas

## Tech Stack
- Python
- PyQt
- pandas
- matplotlib
- MongoDB
